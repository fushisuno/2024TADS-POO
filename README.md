Este repositório contém exemplos e exercícios desenvolvidos durante a disciplina de **Programação Orientada a Objetos (POO)** no **IFPR - Campus Cascavel**, curso TADS.  
Todos os códigos foram implementados em **Java**, focando nos conceitos fundamentais de POO, sem padrões arquiteturais complexos.

---

## ⚙️ Tecnologias e Conceitos
- **Java** → linguagem principal  
- **POO** → conceitos fundamentais: objetos, classes, atributos, métodos  
- **Estruturas de Controle** → if, for, while, switch  
- **Coleções Simples** → arrays e listas  
- **Entrada e Saída** → Scanner, System.out.println

---

## 📌 Conceitos Vistos em Aula

### 🧩 Orientação a Objetos
- **Classe e Objeto:** definição e instanciação  
- **Atributos e Métodos:** características e comportamentos  
- **Encapsulamento:** uso de `private` e métodos `get`/`set`  
- **Herança:** extensão de classes para reaproveitar código  
- **Polimorfismo:** métodos com comportamentos diferentes dependendo da classe  
- **Abstração:** simplificação do modelo do objeto, focando no essencial  

### 📁 Estruturas de Controle
- Condicionais: `if`, `else if`, `else`  
- Laços de repetição: `for`, `while`, `do-while`  
- Estruturas de decisão com `switch`  

### 📚 Coleções Simples
- Arrays e manipulação de elementos  
- Listas básicas (`ArrayList`)
